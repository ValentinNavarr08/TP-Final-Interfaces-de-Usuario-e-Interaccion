# TP-Final-Interfaces-de-Usuario-e-Interaccion
Este proyecto es desarrollado en el contexto de trabajo Practico como final Regular de la materia Interfaces de Usuario e Interaccion.
Consiste en crear un Desing System de una web de una plataforma para mirar series y peliculas estilo Netflix, desde el proceso de maquetado inicial, hasta lograr el diseño final.
